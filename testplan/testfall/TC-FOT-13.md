# TC-FOT-13 · Fota riktig mat med iPhone-kameran

| | |
|---|---|
| **Område** | Fota mat |
| **Prioritet** | Hög |
| **Typ** | 🖐️ Manuell |
| **Krav** | [specs/stories.md US-04, US-05](../../specs/stories.md) |

## Förutsättningar

- iPhone, appen på hemskärmen, Edge Function driftsatt med Gemini-nyckel

## Steg

| # | Gör så här | Förväntat resultat |
|---|---|---|
| 1 | Tryck **Fota maten** | iPhone frågar om kamera eller bildbibliotek |
| 2 | Fota din lunch | Förslag inom ca 5–10 sekunder, delarna stämmer ungefär |
| 3 | Jämför kcal med en manuell sökning på samma mat | Rimlig nivå (AI ger en uppskattning, inte exakt värde) |
| 4 | Justera och spara | Måltiden syns med bild i dagsöversikten |
| 5 | Välj en bild från bildbiblioteket (även HEIC) | Fungerar likadant |
