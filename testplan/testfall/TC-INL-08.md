# TC-INL-08 · Logga in med riktigt konto och Face ID

| | |
|---|---|
| **Område** | Inloggning |
| **Prioritet** | Hög |
| **Typ** | 🖐️ Manuell |
| **Krav** | [specs/stories.md US-01](../../specs/stories.md) |

## Förutsättningar

- iPhone, appen tillagd på hemskärmen
- Lösenordet sparat i iCloud-nyckelringen (från Svampkartan)

## Steg

| # | Gör så här | Förväntat resultat |
|---|---|---|
| 1 | Öppna appen från hemskärmen och tryck i E-post | iPhone föreslår ditt sparade konto |
| 2 | Välj kontot och godkänn med Face ID | E-post och lösenord fylls i |
| 3 | Tryck **Logga in** | Appen visas med din e-post |
